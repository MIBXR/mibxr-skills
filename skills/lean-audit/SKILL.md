# Lean Audit 精简审查

Agent 容易把个人项目当成需要长期维护的团队产品：顺手加测试和校验，为走不到的分支写兜底，在文档里写免责和讨论过程，为一个案例搭抽象。本技能分两步处理：初始化时清掉环境里诱发这些行为的配置，开发完成后找出改动里多出来的部分。

什么算多余，以 [判断规则](references/rules.md) 为唯一标准。

## 选择模式

| 用户的说法 | 模式 |
| --- | --- |
| 第一次使用、“初始化”“检查我的配置”、换了 Agent 或电脑 | 初始化，按 [初始化](references/setup.md) 执行 |
| “开发完了”“检查这次改动”“有没有多做” | 完成审查，按 [完成审查](references/review.md) 执行 |

用户的说法对不上时，问一句：检查环境配置，还是检查这次的改动。

## 脚本

两个脚本只用 Python 3 标准库，只读，输出 JSON，由你逐条判断后交给用户决定。

- `scripts/scan_env.py`：找出当前电脑上各 Agent 的全局指令、配置、记忆与技能，标出诱因句和会自动触发的技能。
- `scripts/scan_diff.py`：扫描一段改动。`flags` 是可以直接判定的多余内容，`review` 是需要逐句判断的文档句子。

参数见各脚本的 `--help`。Windows 上用 `python` 代替 `python3`。
