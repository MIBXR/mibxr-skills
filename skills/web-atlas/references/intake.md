# Web 提问清单

每次只问一到两条，按顺序优先处理会改变决定的未知项。先从现有页面、代码、内容和用户原话推断；推断不出来的才问，用户答不出就使用默认值并记为推断。

依据中的 ID 是 Web Atlas 的案例，可用 `show ID` 查看。

顺序按“为什么问”中列出的独立决定数排序；同数按后续实现的依赖排列。

### Q1　谁会来，看完最该做什么？
- 问题：谁会来，看完最该做什么？
- 为什么问：首屏先呈现的对象、主行动、导航目的地、内容顺序、是否需要筛选、是否需要细察、演示是否可操作，共7项。
- 默认值：以当前内容最明确的受众为主，首屏只突出一个已存在的主要行动；缺信息时标为推断。
- 写入简报：受众；目的；页面任务（看完要做什么）
- 依据：`apple-product`、`digital-dunhuang`、`retro-80s`、`swiss-grid`

### Q2　要扫一眼，还是找资料细看？
- 问题：要扫一眼，还是找资料细看？
- 为什么问：首屏信息密度、章节数量、列表或档案结构、筛选层级、详情展开、章节索引，共6项。
- 默认值：完整保留已有内容；先给可扫读摘要，再允许原位展开；长页用正常滚动。
- 写入简报：内容量与密度；页面任务（看完要做什么）
- 依据：`blue-archive`、`zenless-zone-zero`、`swiss-grid`、`design-sight`

### Q3　哪些现成的东西必须保留？
- 问题：哪些现成的文字、图片、标志或颜色必须保留？
- 为什么问：主视觉素材、图像裁切、字体来源、配色可变范围、字标与形状、可否重绘，共6项。
- 默认值：保留已有品牌与已授权的真实内容；可变部分先用系统字体与原创图形，未知授权不视为可用。
- 写入简报：品牌与素材约束
- 依据：`apple-product`、`bauhaus-geometry`、`rijksmuseum-art`、`line-art`

### Q4　主要在哪看，手机先保住什么？
- 问题：主要在哪看，手机先保住什么？
- 为什么问：断点、列数、长段重排、媒体比例、操作入口位置，共5项。
- 默认值：桌面与窄屏都可读；正文顺序保持，控件另排；只有明确需要保留的舞台等比缩放。
- 写入简报：设备与断点；可访问性、减少动态
- 依据：`chatgpt-platform`、`qoder-platform`、`design-sight`、`rhine-lab`

### Q5　希望什么感觉，最不想像什么？
- 问题：希望什么感觉，最不想像什么？
- 为什么问：底色与强调色、字体语气、轮廓与材料、参考方向排除，共4项。
- 默认值：沿用现场已有且最一致的语气；没有参考就记录“未提供”，不虚构用户喜恶；冲突方向和排除原因写明为推断。
- 写入简报：情绪基调（用户的原话）；喜欢和讨厌的参考；已排除的方向及原因
- 依据：`linear-workflow`、`claude-platform`、`pixel-world`、`line-art`

### Q6　动画是主角，还是安静地待在背景？
- 问题：页面上的动画，你希望是吸引眼球的主角，还是安静地待在背景里？
- 为什么问：首要信息到达时间、自然滚动或场景交接、自动运动生命周期、声音与暂停/减少动态，共4项。
- 默认值：正文立即可读，正常滚动；非必要运动可暂停并响应减少动态，声音默认关闭后主动启用。
- 写入简报：可访问性、减少动态；情绪基调（用户的原话）
- 依据：`met-museum`、`zelda-world`、`line-art`、`arknights-world`

### Q7　放进已有网站，还是单独做一个？
- 先从现场推断：有项目代码时，直接读技术栈、组件与依赖，不问这一条。
- 问题：这个页面要放进已有的网站，还是单独做一个？
- 为什么问：组件复用方式、外部依赖、演示隔离、静态回退，共4项。
- 默认值：沿用现场技术栈与组件；没有既有工程时采用原生HTML/CSS/JS；复杂演示限局部，不扩散依赖。
- 写入简报：技术栈、已有组件；品牌与素材约束
- 依据：`bauhaus-geometry`、`deepseek-harness`、`pixel-world`、`arknights-world`
