# 桌宠制作与修复

把用户认可的角色基准、正式安装图集和展示预览分别记录，交付可追溯的修改。格式由当前目标应用决定，角色比例与画风由本次用户要求决定。

## 定位任务

先从作品目录、清单和应用记录确定目标、最新正式素材、已选中的宠物及授权范围。比较内容哈希与来源，文件修改时间和同名记录不足以确认版本。

- 新制作：从参考确定外形、关键特征与主要动作，建立可比较的基准；尚缺会改变角色身份的决策时再向用户提问。
- 局部修复：保存正式输入和哈希，圈定动作行、帧与允许改变的特征；先读 [动作修复](references/animation-repair.md)。
- 迁移或重新打包：保留正式图片字节，先读 [交付与导入](references/delivery.md)，从现有配置和清单恢复内容。

执行图像生成、修图或 Pets 导入时，使用当前环境已提供且适用于任务的工具或技能。能力缺失时继续完成不依赖它的检查，明确剩余步骤；技能本身不提供生成服务、应用认证或安装接口。

## 制作与验证

1. **确认格式**：读目标应用当前的图集结构、有效帧数、透明格与播放规则。把设计节奏、模拟应用预览和实际应用观察分开记录。
2. **执行限定变更**：以用户认可的基准对照整组动作，选择与问题相符的处理方法，保留有意的步态、跳跃和局部运动。
3. **验证最终编码文件**：从交付图集重新解码动作，检查应用显示尺寸、放大细节、循环末首帧及状态切换。结构合法不证明表情、色彩和稳定性合格。
4. **检查未修改范围**：保留前后图集时，可用 `scripts/compare_atlas.py` 检查授权行以外的像素是否变化。它只验证像素保留，不能替代视觉判断、官方格式校验或实际播放。
5. **回读真实结果**：涉及上传、更新或安装时遵循 [交付与导入](references/delivery.md)。实际播放无法观察时，列出已验证层级和未验证层级。

图集比较示例（参数来自当前作品格式；行号从 1 开始）：

```sh
python scripts/compare_atlas.py --before before.png --after after.png --columns 8 --rows 11 --allow-rows 4
```

路径相对于本技能目录；脚本需要 Pillow。同一行内还有未授权区域时，在项目中做更细的像素区域比较。

## 保存结果

作品仓库保存正式素材、源图、提示词、采用的修订和对应验证证据，来源署名随素材保留。通用技能只保存可复用方法。版本相关帧时长、角色偏好和账号记录留在作品上下文中，并注明验证时间。

交付说明写清修改范围、文件位置、已执行验证及剩余限制。旧 QA 标注为历史证据；生成预览、下载成功、上传成功和应用中可见是不同的完成条件。
