# 宠物网站的高清素材与透明边缘

用于网站静态插画或动画变糊、大小不协调、混用旧素材，或去背景后出现杂色边缘的情况。

## 先查已有素材

区分高清静态主图、生成的连续动作原稿、加工后的高分辨率动作帧、正式应用图集与下载包。先查保存的原稿和已解包资源，避免反复从最小成品帧放大。

确定每项素材对应的角色、动作与当前修订。较早的高清图不一定比最新小图更适合直接使用：它可能仍含已修复的眼睛、配色、配饰或比例问题。

原稿与成品都保留原有用途。网页可以使用自己的高清资源，正式下载仍提供对应应用需要的成品；放大展示的资源不应悄悄替换安装输入。

## 三种像素不要混淆

| 指标 | 能说明什么 |
| --- | --- |
| 画布或存储尺寸 | 文件有多大、显示容器如何安排；留白和上采样也会增加这个数字。 |
| 每帧源像素 | 动画的单帧从哪种分辨率素材取得，是否已经经过缩放。 |
| 人物有效像素 | 角色轮廓实际占据多少像素，以及头发、眼睛和线条还能保留多少细节。 |

把 192×208 的成品帧放大到更大画布不会增加原有细节。这个尺寸只是低分辨率输入的示例，实际以当前作品为准。

网页显示协调依靠可见轮廓高度、视觉中心与落点，而不是简单令两张含不同留白的图片拥有相同 CSS 宽度。保留清晰静态原图，调整显示位置与尺寸来匹配动画。

## 恢复高清动画

从保存的高清动作原稿提取姿态，保持角色比例，并与最新正式作品的姿态、配色、固定特征及修复结果对照。优先使用保留细节的来源，减少重复缩放。

一组动作共用稳定的对齐依据。用躯干与下方落点协调显示，避免把每帧变化的手臂、头发或效果边缘当成居中依据。真实腾空、步态和头部转向应保留。

核对首屏、角色介绍、动作剧场与安装卡片实际加载的来源，避免某一处仍使用旧的低清预览。高清资源不可用时明确报告限制或展示已标明的替代，不把低清回退称为高清恢复。

时序与网页实际体验相符；若展示节奏不同于目标桌宠应用，明确其预览用途，不把它当作应用播放证据。

## 去背景与去染色是两件事

移除纯色底只解决背景透明问题，抗锯齿边缘可能仍混入底色。分别查看 alpha 的范围和轮廓 RGB 的残留，使用当前工具规则允许的方法处理。

清理目标是污染颜色，正常墨线、衣服颜色、虹膜和原有半透明细节要保留。不能按一个简单颜色条件抹掉角色内部相近色，也不能为了去杂边把轮廓侵蚀或变粗。

在浅色与深色背景上放大检查，同时回到实际显示尺寸看整组动画。静止帧没有明显问题，跑动、失落与转头时仍可能暴露暗边或闪边。

## 修改后的核对范围

单张图修复先核对该图及它出现的页面位置；修改共用去背景、缩放或配色处理时，查看受影响作品的全部动作和方向，包括循环与分段接缝。

比较原稿、加工结果与网页加载的最终文件，确认用到的确实是最新版本。资源改变后更新缓存标识；仅替换本地文件不能证明线上已经取到新素材。

源图和临时处理记录留在任务需要的位置。网站保存能直接使用的图片、动作条带和运行数据即可，不强制额外保存一套“网站素材加工依据”或处理工程。
