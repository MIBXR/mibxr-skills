# 角色与动作制作

用于新建桌宠、增加动作，或需要重新绘制一组姿态的情况。现有成品的局部问题先判断是否需要重画。

## 先联网研究角色

决定动作前主动使用网络搜索，先确认角色名称、作品和用户选定的形态或版本，再查角色特点、官方设定、招牌动作、癖好、惯用道具、神情与身体语言，以及同人社区的代表性解读。可使用角色原文名与“设定、动作、习惯、表情”等关键词，查看原始页面、图片或片段，不只依赖搜索摘要。

官方角色介绍、设定集和原作品片段用于确认事实；同人社区、讨论与插画用于扩充动作灵感。给结论标明是官方设定、社区解读还是本次创意建议，存在冲突时说明并让用户选择。原创角色没有官方资料时，以用户提供的设定为准，搜索相近性格和动作参考，不补造角色事实。

将研究结果转成可设计的线索：某种习惯适合哪个状态，招牌动作如何缩成小幅动画，常用道具如何帮助表达性格。把辨识度安排在合适的动作中，让安静状态也保持自然，避免所有状态反复使用同一手势或道具。找不到充分依据时如实说明，仍可给出标明为创意的候选。

在创作记录中保存实际采用的来源链接、参考图片或片段位置、用途和必要署名，让动作思路可以追溯。资料访问不了或搜索能力不可用时说明缺口，取得用户对替代依据的决定，不宣称已完成网络研究。

## 逐动作提案，先取得确认

读取当前协议的全部待制作状态及实际触发含义。保持状态与应用用途对应，动作的视觉表达可以结合角色特点发挥：忙碌可表现角色的专长，等待可带出它的小习惯，成功回应可采用招牌姿态。通用动作表是设计问题的参照，最终方案由当前角色和用户决定。

正式制作前，对每个待制作动作询问用户希望如何设计，同时给出推荐方案和有实际区别的替代方向。可以用一份逐动作表集中沟通，不必逐项开启新一轮提问，但每一项都需要获得明确决定。提案写清：

- 状态与触发用途，以及准备表达的情绪或行为。
- 来自角色研究的特点、习惯或招牌姿态，并链接依据。
- 推荐的动作故事、代表姿态与道具；有必要时给出替代方向。
- 哪些部位保持稳定、哪些运动，以及构图和空间要求。
- 需要用户选择或调整的地方，包括待机与注视方向的表达方式。

用户可以一次确认整份明确列出的方案，也可以分批选择；“按推荐方案”只覆盖已经列出的具体内容。缺项或用户要求改动时先补齐和对齐，不能把尚未讨论的动作默认为已批准。整体制作授权不替代逐动作设计确认。

## 关键设计图再次确认后制作

逐动作方案确认后，先用规定的图像工具生成一版关键设计图。图中展示主形象和每个待制作动作的代表姿态，复杂动作可用少量关键姿态说明起点、高潮与回位；同时让用户看清神情、道具、构图和角色固定特征。注视设计展示关键方向即可，此时尚不铺开全部动画帧。

向用户展示实际图片，并说明它与已确认方案的对应关系，询问需要保留或修改的地方。关键设计图确认前，停在设计图阶段；修改后展示修订图，再取得确认。方案确认与设计图确认是两次不同的内容决定，用户尚未回复不能视作认可。

设计图确认后，以确认的形象、关键姿态和动作方案为依据，才展开完整动作序列、方向过渡和正式图集。后续需要改变动作含义、关键姿态、道具或形象时，回到受影响内容的确认环节。

分别沿用已明确认可的动作方案与设计图：已完成的确认节点可以复用，缺少的节点仍须补齐。仅修复既有动作的位置、颜色或透明边缘而不改变设计时，按[动作修复](animation-repair.md)处理；新增或重新设计部分仍遵循两次确认。

## 给参考分工

| 参考类型 | 从中取什么 | 保持什么边界 |
| --- | --- | --- |
| 角色身份 | 发型、耳朵、服装、配饰、尾巴、眼睛结构等可辨认特征 | 多张参考冲突时以用户选定版本为准。 |
| 画风 | 线条、色块、纹理、阴影、头身比例与构图 | 画风参考中的其他人物、背景和文字不随之搬入。 |
| 已认可主形象或待机 | 本次作品的比例、材质颜色、表情和落点 | 修复继续以最新认可版本为准，避免旧参考盖过新决定。 |
| 动作与表情 | 姿态顺序、受力、手势和情绪 | 参考可能来自不同画风，只提取动作语义。 |

主形象应在目标显示尺寸仍可辨认。全身与半身、手绘与像素等由本次用户决定；同一角色不同款式分别保留自己的形象基准。

在创作记录中留下重要的参考分工与署名。角色出处、原插画作者、AI 辅助制作与素材整理是不同贡献，按实际来源描述。

## 把动作拆成能读懂的变化

先写静止部分、运动部分、起点、高潮和回位，再决定每帧的姿态。帧数服从目标格式，动作节奏同时考虑应用如何停留与循环。

| 状态 | 可以检查的设计问题 |
| --- | --- |
| 待机 | 角色安静时是否自然？眨眼有合理的闭合与睁开过程，停顿是否适合应用的真实时序？ |
| 左右移动 | 是否看得出方向与交替步态？半身构图用上肢与发尾表达移动时，仍保持原构图。 |
| 挥手 | 手臂如何抬起、回应和回位？肩部、躯干与站立落点是否稳定？ |
| 跳跃 | 蓄力、离地、最高点与落地是否清楚？用真实位移表达腾空，保持角色尺度。 |
| 失败或失落 | 情绪是否由表情和姿态表达？回到日常状态的过程是否自然？ |
| 等待回应 | 是否像在耐心等待，而非机械摇头？歪头、眨眼或状态符号只是按角色选择的表达方式。 |
| 工作 | 角色究竟在做什么？敲键盘、制作东西、应援等都应有可辨认的行为与对象。 |
| 检查与思考 | 视线、姿态与手中对象能否表达检查，且与等待、挥手有所区别？ |

这些状态是常见设计参照；具体名称和数量以目标应用为准。辅助效果若属于用户的设计，就纳入完整动作和空间预算。

## 写清一组生成提示词

一组动作尽量共同生成，统一角色大小、配色与线条。提示词可按下面的内容组织，按工具实际输入方式填写：

1. **产物与范围**：主形象、一条动作序列，还是已有动作的局部重绘。
2. **参考分工**：哪张定义角色，哪张只提供动作，哪张是最新颜色与比例依据。
3. **固定特征**：本角色必须保留的形状、部件数量、左右位置、眼睛结构和画风。
4. **动作分镜**：按顺序写每个姿态，并明确画面左与右；区分必须静止和允许运动的部位。
5. **尺度与构图**：整组共同的大小与落点，跳跃等有意变化单独说明。
6. **输出空间**：完整轮廓、相邻人物间隔、四周留白、背景或透明要求，给配饰和效果留余地。
7. **本次修订**：只描述要修的缺陷，同时说明哪些已认可的内容要保留。

保存实际采用的文字与输出，而不是只留一段概括。工具或模型信息有记录时保留可移植描述；不要补写未知调用参数。布局辅助图仅用于排布时，要在提示词里说明其标记不属于画面。

## 注视方向

先建立清楚的上、右、下、左等主要朝向，再补中间过渡。固定身体和下方落点，让头、脸部平面与眼睛自然俯仰和转向，配饰适度跟随。

左右含义采用统一的画面坐标。非对称配饰、手中物和尾巴不能因简单镜像而跑到错误位置。眼睛的画法来自当前角色：有瞳孔的保持结构，没有瞳孔的也不为了表达视线擅自增加。

分两条原稿保存时，连起来查看中间接缝与整圈首尾。既要能辨认方向，也要保持同一个角色；剩余方向歧义如实说明。

## 保存供下次继续创作的材料

保存采用的角色研究来源、参考、主形象、已确认的逐动作方案与关键设计图、实际提示词、高清生成图和最终成品，并让制作说明链接到对应文件。确认决定用简明文字与对应图记录即可。保留有创作价值的设计稿；重复试验、临时布局和运行日志按需留在工作区。

生成原图带纯色底、尚未选帧或与最终图集尺寸不同，都应按其真实用途描述。它们保留制作细节，不构成未来能够再次生成相同图像的保证。
