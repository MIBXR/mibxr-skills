# 来源与维护

经验来自 Suzuka Pets 与 Hibiki 的制作、局部修复和作品整理。作品仓库保存角色与创作资料，本仓库保存通用方法。

先尊重用户的仓库定位。作品展需要易读的创作记录与成品；可复现加工项目才需要对应程序和依赖。网站与宠物可以独立保存。把一次制作中用过的工具全部持久化，会给作品目录增加无关维护负担。

新增经验应改变未来任务中的具体决策，并写明适用条件。角色画风、一次性参数、机器路径和账号状态不成为通用规则。

技能采用 SKILL.md、按需参考文档和可选助手脚本组织。修改后检查格式、引用和实际决策；仅当脚本改变时重跑它的相关测试。安装方法见仓库 README。
